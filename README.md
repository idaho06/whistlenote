# whistlenote

A desktop app for Linux and Windows that shows the note you whistle, estimates tempo from claps or taps, records a melody against a metronome and exports it as MIDI or CSV.

```sh
git clone https://github.com/idaho06/whistlenote.git
cd whistlenote
cargo run --release
```

Linux packages: Arch `alsa-lib`; Debian/Ubuntu `pkg-config libasound2-dev libxkbcommon-dev libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev`.
